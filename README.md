# hj202608m1

Python & Git 기초 미션 리포지토리입니다.

## 프로젝트 구성

- `.gitignore`: Git 버전 관리에서 제외할 Python 임시 파일 및 편집기 설정
- `hello.py`: Python 실행 확인용 스크립트
- `prompt_manager.py`: 콘솔 기반 프롬프트 관리 프로그램

## 실행 방법

1. Python 버전 확인

```bash
python --version
```

2. 프로그램 실행

```bash
python prompt_manager.py
```

3. 메뉴에서 번호를 선택하여 다음 기능을 사용합니다.

- 프롬프트 목록 보기
- 카테고리별 보기
- 검색
- 상세 보기
- 즐겨찾기 토글
- 즐겨찾기 목록
- 새 프롬프트 추가
